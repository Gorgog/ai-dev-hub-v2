## What

Урок приходит в момент, когда его признак виден в вызове (инструмент + регэксп команды, пути или вывода),
один раз на эпоху агента, через модуль подачи. Любая запись урока проверяется сразу: битый frontmatter, NUL,
не-UTF-8, длинная первая строка, некомпилируемый `when`, пустой `source`, URL или команды
пуша/отправки/удаления в тексте — блок с причиной. История памяти коммитится хуком под `flock`.

## How

- Размер: M (калибровочно). Поток H, волна 2.
- Касания: модули PreToolUse / PostToolUse(Edit|Write|Bash) / Stop / SessionStart, записи реестра;
  горячие точки: каркас хуков.
- Горячий путь читает только `.triggers.json` (выводимый, срез 12) и файл своей сессии; SQLite не открывает.
- Проверка записи зовёт валидатор библиотеки памяти (срез 12) — одна логика для хука и для миграции.
- Коммит памяти: Stop, `flock` с таймаутом 0 — занято, пропустить до следующего Stop (цифры P14).
- Предполётная проверка памяти на SessionStart (порча называется, вызовы не блокируются).
- Поиск по UserPromptSubmit и PostToolUseFailure — не строим, пока replay 32 не покажет пользы.
- Prior art: rules-guard (регэкспы по полям вызова), предполётная проверка `session-start.cjs`.
