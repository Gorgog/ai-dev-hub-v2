## What

Хаб v2 ставится и работает рядом с v1, не задевая его: свой маркетплейс, свой корень, свои данные плагина.
Каждое событие хука — один процесс node, поведение — модули в каталоге события; хаб можно выключить одной
переменной; на старте сессии видно, здоров ли он. Каждый механизм записан в реестр, бюджет проверяет
pre-commit. Поведение v1 (замок, rules-guard, бриф, done-gate) переезжает модулями без изменений — полигон
показывает тот же результат, что на `ef519e3`.

## How

- Размер: L (калибровочно). Поток H, волна 1, один поток.
- Касания: `plugin/hooks/` (раннер событий, каталоги модулей, перенос модулей v1), `plugin/mechanisms/`,
  `install.cjs`, `sync-claude.sh`, `.claude-plugin/`, `plugin/.claude-plugin/plugin.json`, `.githooks/pre-commit`;
  горячие точки: каркас хуков (весь), `.githooks/pre-commit`, `install.cjs`.
- Раннер: событие → модули своего каталога по порядку имени; модуль возвращает решение или текст для подачи,
  в контекст пишет только модуль подачи (срез 08; до него — прямой вывод, как в v1). Новый модуль = новый
  файл, общего списка нет.
- Политика отказа: модуль подачи и напоминаний — fail-open с записью в журнал ошибок хаба; модули защиты
  (deny опасного, замок ресурсов) — fail-closed с причиной. `HUB_OFF=1` выключает все модули — работа
  идёт «голым» Claude Code. Проверка здоровья на SessionStart: конфиги разбираются, node и
  `node:sqlite` есть, корень найден, версия плагина = коммит хаба.
- Корень хаба: из `userConfig.hubPath` / `AI_DEV_HUB`, не из маркетплейса `hub` (тот указывает на v1).
  Маркетплейс `hub-v2`, плагин `hub` — команды `/hub:*` те же; переключение и откат — строкой
  `enabledPlugins`. Итог P3/P12 решает детали. `version` в `plugin.json`, `claude plugin validate` в pre-commit.
- Метка версии хаба (короткий sha) — в каждой строке журналов хуков и в шапке брифа.
- Реестр: `plugin/mechanisms/<id>.json` — событие, логический обработчик, файлы состояния, сценарий
  полигона, что заменяет, дата пересмотра. pre-commit: механизм без записи или без сценария — отказ;
  обработчиков > 6 или видов состояния > 10 — отказ с перечнем; истёкший пересмотр — предупреждение.
- Список вырезаемого из v1 (в реестр со статусом «убран»): `journal-summary.cjs`, `brief.json` и рукописный
  разделённый индекс (индекс станет выводимым — срез 12), `cd-no-subshell` (по итогу P1), `mutants*` без
  дорожки M — по таблице «механизм → файл → что заменяет», которую срез сводит до кода.
- README: Node ≥ 22 (нужен `node:sqlite`).
- Prior art: `pretool.cjs` (уже один процесс на два механизма), `session-start.cjs`, `stop.cjs`, тесты v1.
