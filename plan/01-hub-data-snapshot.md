## What

Всё, на чём стоят базовая линия, полигон, replay и миграция памяти, лежит копией в `~/hub-data/` с
контрольными суммами и переживает уборку журналов и смерть временных папок. v1 при этом не меняется ни на
байт. Скрипт снимка повторяем: при переходе проектов он снимет дельту.

## How

- Размер: S (калибровочно). Поток A волны 0, первым — журналы уязвимы.
- Касания: новый каталог `tools/hub-data/` (скрипт снимка, сверки, скан секретов); данные — только в
  `~/hub-data/` (права 700); горячие точки: нет.
- Журналы сессий `~/.claude/projects` (≈2,5 ГБ, ≈1090 файлов, с 27.08) → `~/hub-data/journals/` + манифест
  sha256; повторный запуск докладывает только новое и изменённое. Скан секретов на копии (токены, ключи,
  `.env`-строки) — отчёт со списком файлов, без значений.
- Память и логи проектов v1 (`projects/*/memory`, `rules.json`, `dispatch-rules.json`, `checks.json`,
  `brief.json`, профили, `rules-guard.log`, `dispatch-guard.log`, `dispatch-grants.json`), `research/` целиком
  (прототипы полигона, памяти, скорости) → `~/hub-data/v1/`. Копирование только чтением.
- `calls.db` из прототипа памяти лежит во временной папке чужой сессии: скопировать, если жив, и в любом
  случае пересобрать из копии журналов (срез 02 доводит экстрактор).
- Репозитории проектов: `git status`, `stash list`, число локальных веток и веток без remote — в отчёт;
  `git bundle create --all` в `~/hub-data/bundles/`. Только чтение репозитория: ни `fetch`, ни `worktree add`.
- Срок хранения журналов (365 дней) ставит диспетчер (Georgy 05.11); копия делается независимо от этого.
- Списка запретных имён в v2 нет: в git — только код; дифф на реальные данные, имена проектов и ключи задач
  проверяет ревьюер (plan.md § Данные).
- Prior art: копирование с манифестом — нет в хабе; скан секретов — шаблоны из `hub-evals` (`fake-eval-token`).
